# Guide des quatre présentateurs

Le minutage détaillé de chaque slide figure dans les notes, accessibles en mode répétition et dans Admin. Total indicatif : 45 minutes. Les intervenants doivent se répartir les transitions : le premier introduit, le quatrième ouvre le coffre, les quatre commentent la solution. Pour un temps plus court, supprimer des slides académiques secondaires sans sauter les quatre manches.

| Responsable | Slides | Actions |
|---|---|---|
| P1 | 1–12 | Accroche, règles, ScreenConnect réel vs Atlas fictif, rôle DGSSI, mission 1 |
| P2 | 13–21 | Loi, décret, DNSSI approfondie, évaluation des écarts, mission 2 |
| P3 | 22–28 | PCA/PRA, BIA/RTO/RPO, architecture, mission 3 |
| P4 | 29–36 | CERT, maCERT, réponse, mission 4 et coffre |
| Tous | 37–40 | Solution commentée, retour d’expérience, conclusion et sources |

## Conduite en classe

Avant : imprimer uniquement la fiche de mission et les cartes étudiantes du dossier, préparer un PC avec l'admin et un écran de projection séparé, tester avec deux téléphones sur le réseau de la salle. Créer une nouvelle salle, diffuser le lien étudiant et le code. Donner 45 secondes pour l'inscription. Un téléphone par équipe.

Pendant : annoncer que des indices se trouvent dans les slides et demander aux étudiants de remplir la question d'application de chaque partie. Les indices sont les encadrés du cas Atlas et les références DNSSI. Ne pas montrer la correction ni le code avant la finale. Chaque challenge est affiché dans la projection ; l'admin ouvre la manche, les téléphones changent automatiquement. Fermer quand le temps est écoulé. Les chiffres candidats sont calculés sur les téléphones. L'admin peut observer les scores sans les projeter. Les quatre questions de l'étude de cas sont une activité d'application progressive non notée automatiquement ; demander une justification orale.

Finale : chaque équipe annonce ou montre son code candidat ; le classement automatique départage les équipes. L'admin saisit le code correct (voir la fiche de correction) puis passe aux slides de solution. Si toutes les équipes ont échoué, expliquer les solutions et ouvrir tout de même le coffre avec le code correct. Le but reste pédagogique.

## Transitions proposées

- P1 → P2 : « Nous savons désormais qui organise la réponse ; sur quelles exigences juridiques et techniques repose cette responsabilité ? »
- P2 → P3 : « L’analyse des écarts révèle des faiblesses. Si l’on suspend les accès, comment maintenir les soins ? »
- P3 → P4 : « La continuité est organisée, mais avant toute restauration, comment traiter la compromission ? »
- P4 → finale : « Les quatre clés sont réunies ; ouvrons le dossier de remédiation et comparons nos décisions. »

## Évaluation

Jeu : 25 points par manche correcte. Analyse de cas : 4 questions de 5 points (exactitude du concept 2, pertinence de l'action 2, justification ou preuve 1). Évaluation du référentiel : vérifier la précision des références, la distinction entre exigence et recommandation, les preuves et la hiérarchisation. Le score de jeu est distinct de ce barème pédagogique.
